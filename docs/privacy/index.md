# Parallel-Draft プライバシーポリシー

最終更新日：2026 年 8 月 21 日

Parallel-Draft（以下「本アプリ」）は、PDF 図面の差分を表示する Windows デスクトップアプリです。
本ページは、本アプリが扱う情報について説明します。

## 収集する情報

**ありません。**

本アプリは、個人情報、アカウント情報、利用状況（テレメトリ）、
図面の内容、ファイル名のいずれも収集しません。
開発者は、誰が本アプリを何回どのように使ったかを知る手段を持ちません。

## 図面ファイルの扱い

読み込んだ PDF、比較の結果、書き出した画像や一覧は、
**すべてお使いの PC の中だけで処理・保存されます。外部へ送信されることはありません。**

本アプリが読むファイルは、利用者が「開く」操作で選んだもの、
またはウィンドウへドラッグ＆ドロップしたものに限られます。
PC 内のファイルを自動で探すことはありません。

## ネットワーク通信

本アプリがネットワークにアクセスするのは、次の場合だけです。

- Microsoft Store でのライセンス確認（本アプリを利用する権利があるかの確認）
- Microsoft Store 経由での更新（Windows が行います）

いずれの通信にも、図面の内容やファイル名は含まれません。

## PC の中に保存されるもの

次のものが、お使いの PC のローカルフォルダーに保存されます。これらは送信されません。
Microsoft Store から入れた場合、置き場所は本アプリ専用の次のフォルダーで、
**アンインストールすると一緒に消えます**。

```
%LocalAppData%\Packages\msmsrep.Parallel-Draft_77t1an0ygyrva\LocalState\
```

| 保存されるもの | ファイル | 内容 |
| --- | --- | --- |
| 設定 | `settings.json` | ウィンドウサイズ、表示モード、感度、背景色、最近開いたファイルのパス |
| ライセンスの記録 | `license.dat` | 試用の開始日と購入状態 |
| 動作の記録（ログ） | `logs\` | エラーの発生日時と種類。**図面の内容は含みません**（ファイル名はハッシュ化して記録します） |

ログは直近 7 日分だけを残し、古いものは自動的に削除されます。
設定画面から保存フォルダーを開けます。

アンインストールすると、上記のフォルダーごと削除されます。

## 第三者への提供

提供する情報がないため、第三者への提供もありません。
広告・解析のためのライブラリやサービスは一切組み込んでいません。
